Ковкасян пленница — сайт-меню для Vercel

Файлы:
- index.html — основной сайт со встроенными стилями, скриптами и изображениями
- vercel.json — конфигурация статического проекта

Публикация:
1. Распакуйте архив.
2. Поместите файлы в корень проекта Vercel (или репозитория GitHub, связанного с Vercel).
3. Framework Preset: Other; Build Command: пусто; Output Directory: пусто.
4. Запустите Deploy.
