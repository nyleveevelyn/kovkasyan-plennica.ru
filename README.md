# Ковкасян пленница — Vercel project

Готовый статический проект.

Файлы:
- index.html — главная страница
- vercel.json — настройки Vercel

Для деплоя:
1. Распакуйте ZIP.
2. Загрузите папку в GitHub и импортируйте репозиторий в Vercel
   или выполните `vercel` / `vercel --prod` из этой папки через Vercel CLI.
3. Framework Preset: Other.
4. Build Command: оставить пустым.
5. Output Directory: оставить пустым.
